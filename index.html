About TOUCH

TOUCH (Transforming Oral Understanding into Clear HandSigns) is an assistive technology platform designed to bridge the accessibility gap between hearing/speaking individuals and the sign-language community.

By utilizing deep neural network landmarks tracking in real-time, the system interprets complex physical expressions into textual and audio equivalents. Reciprocally, our procedural 3D avatar joints control engine converts standard verbal requests into precise, high-fidelity skeletal animations.

How It Works

Direction 1: Hand Sign → Text

Camera Feed → Landmark Extraction (MediaPipe) → Gesture Classifier → Text & Speech Output

Direction 2: Voice → 3D Sign

Microphone Capture → Speech Recognition (Speech-to-Text) → Dictionary Mapping → 3D skeletal Animation
layers

Technology Stack

  • MediaPipe Hands

    Real-time pipeline to extract 21 high-fidelity 3D coordinates per hand directly in the browser.

  • Three.js Engine

    Hardware-accelerated rendering of a detailed hand mesh with hierarchical rotational bones.

  • Web Speech API

    Cross-browser SpeechRecognition (microphone translation) and SpeechSynthesis (Text-to-Speech voicing).

  • Modern CSS Layouts

    Glassmorphic interface featuring CSS Grid, Custom Variables, Light/Dark configurations, and GPU animations.
